Thesis demo — consolidated parameter snapshot

Source of truth
 - Runner: `Models/run_thesis_optimizer_demo.py`
 - Solver/model: `Models/optimizer_mip.py` (`solve_mip`, `build_arcs`)

This file lists the parameter values actually used by the thesis demo runs so Chapter 3/4/5 can cite a single consistent snapshot.


A) Demo runner defaults (CLI)
 - `--time-limit-sec`: 60
 - `--output-prefix`: "thesis"
 - `--missing-reposition-days`: 1.0 (fallback reposition time when a port-pair distance is unavailable)
 - `--overlap-tolerance-sec`: 60.0
 - `--require-gates`: false (when true, exits non-zero on strict gate failure)
 - `--skip-gantt`: false
 - `--min-dest-port-coverage`: 0.90 (minimum acceptable DEST_PORT_ID non-null coverage for the effective optimiser set)
 - `--require-dest-port-coverage`: false (when true, fail fast before solve if DEST coverage is below threshold)


B) MIP + arc construction parameters (shared by BOTH thesis demo runs)
Passed from `Models/run_thesis_optimizer_demo.py` into `solve_mip(...)`:
 - `time_limit_sec`: 60
 - `max_arcs_per_job`: 6
 - `window_slack_days`: 3.0
 - `job_job_selection`: "reposition"
 - `job_job_candidate_window`: 30
 - `missing_reposition_days`: 1.0
 - `preferred_vessels`: voyage→vessel mapping from `fleet_plan_manual.csv` (if present); used only for an optional mismatch penalty.
 - `switch_penalty`: 0.5 (added to an arc’s cost if the selected vessel != preferred vessel for that voyage)

Defaults from `Models/optimizer_mip.py:solve_mip` (not overridden by the demo runner):
 - `default_speed_knots`: 12.0 (fallback speed used when distances are available for reposition estimates and when the sailing-time predictor falls back)
 - `default_turnaround_days`: 1.0 (fallback turnaround used when the turnaround predictor fails)
 - `cost_scale`: 1_000_000.0 (scales the economic term in the arc cost)
 - `time_weight`: 0.1 (multiplies reposition time in days inside the arc cost)
 - `enforce_nonoverlap`: false (quadratic disjunctive non-overlap constraints are disabled)
 - `min_job_duration_days`: 0.01 (lower bound on per-voyage duration to avoid degeneracy/cycles)
 - `max_late_days`: None (no explicit lateness cap unless provided)
 - `vessel_used_penalty`: 0.0 (default; optional fixed penalty per activated vessel)


C) Laycan policy parameters (differs between the two demo runs)
Shared semantics
 - Laycan start is always enforced as a hard lower bound: `start_time >= laycan_start` (when `LAYCAN_START_UTC` exists).
 - Laycan end is either (i) enforced as a hard upper bound or (ii) relaxed using a non-negative lateness slack variable.

Run 1 (headline): `manual_match_physical`
 - `hard_laycan_end`: True (enforces `start_time <= laycan_end` when `LAYCAN_END_UTC` exists)
 - `unserved_penalty`: 10_000_000.0
 - `late_penalty_scale`: not used (late penalty term coefficient becomes 0.0 when `hard_laycan_end=True`)

Run 2 (contrast): `manual_match_coverage`
 - `hard_laycan_end`: False (enforces `start_time <= laycan_end + late`, with `late >= 0`)
 - `unserved_penalty`: 5_000_000.0
 - `late_penalty_scale`: 0.001
 - Implied lateness penalty per day in the objective: `unserved_penalty * late_penalty_scale = 5_000_000.0 * 0.001 = 5_000.0` (cost units)


D) Objective terms enabled in the thesis demo
The MIP is a minimisation problem with three top-level components:

1) Arc cost term (for every selected arc)
 - Economic term (scaled): `(sum(cost_components) - revenue - various_revenue) / cost_scale`
   * cost_components includes: `FREIGHT_COST`, `PORT_COST`, `HANDLING_COST`, `VOYAGE_CANAL_COST`, `FO_COST`, `DO_COST`, `VARIOUS_COST`, `RUNNING_COST`
   * revenue uses `NET_FREIGHT` if present, else `GROSS_FREIGHT`, else `FREIGHT` (missing treated as 0)
 - Reposition time term: `time_weight * reposition_days`
 - Preferred-vessel mismatch penalty (optional): `switch_penalty` if `preferred_vessels[voyage]` exists and differs from the chosen vessel

2) Unserved penalty term (for each voyage not served)
 - `unserved_penalty * y_voyage` where `y_voyage` is binary and indicates the voyage is left unassigned

3) Lateness penalty term (coverage run only)
 - When `hard_laycan_end=False`: `(unserved_penalty * late_penalty_scale) * late_voyage`
 - When `hard_laycan_end=True`: lateness variables exist but are multiplied by 0.0 (inactive)
